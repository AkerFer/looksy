# Looksy Web — этап 6

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion, Lucide.
Русский адаптивный интерфейс с светлой/тёмной темой. Настоящий Django backend,
сессионный вход и приватные фотографии; никаких демонстрационных гардеробов.

## Запуск

Нужен Node.js **24 LTS**; `node --version` должен показывать v24.x.x.
Проверено на Node 24.22.1 (версия в .nvmrc) и Python 3.12.
После обновления Node.js полностью перезапустите VS Code. Проект проверяет
версию перед запуском и при установке зависимостей.
Сначала запустите backend и PostgreSQL по корневому README.

```bash
cd /workspace/looksy/frontend
npm ci
# Не перезаписывайте существующий .env.local:
cp .env.example .env.local
npm run dev
```

В облачной среде с недоступным домашним npm cache используйте
`npm ci --cache /workspace/.npm-cache`. Frontend: порт 3000; backend: 8000.

```bash
npm run typecheck
npm run build
npm run start
```

BACKEND_URL — серверная настройка reverse proxy, не NEXT_PUBLIC переменная.
Для production задайте её **до сборки**, затем пересоберите Next.js.
Секреты Django остаются только в backend-окружении. Существующий .env.local
не нужно создавать для запуска с адресом backend по умолчанию.

## Браузерные тесты

Backend с применёнными миграциями и Next.js должны быть запущены; тесты
автоматически серверы не поднимают и не используют подмену API.

```bash
npm run test:e2e
```

По умолчанию используется системный `/usr/bin/chromium`, можно указать
CHROMIUM_PATH. Для другого frontend-адреса задайте WEB_URL и включите его origin
в DJANGO_CSRF_TRUSTED_ORIGINS. Origin очистки и анонимный контекст используют тот же WEB_URL.
Тесты создают временного пользователя и удаляют его данные в конце.
Синтетическая фотография tests/fixtures/shirt.png нужна только для теста
загрузки, не показывается посетителям как их вещь.

Тест проверяет регистрацию, session cookie HttpOnly, пустой гардероб, фото,
закрытый доступ к фото анониму, создание/редактирование/поиск, генератор,
избранное, оценку образа, календарь, выход и вход, стилиста в режиме rules,
сохранение профиля, тему, мобильное меню/ширину и удаление аккаунта.
Отдельно проверяются публичная landing и редирект защищённой страницы.
Артефакты при ошибке — test-results; они могут содержать тестовые фото и данные,
не публикуйте traces настоящих аккаунтов.

См. [полное описание этапа 6](../docs/stage-6.md).

Если появляется require() of ES Module magic-string, npm не видит package.json
или отсутствует Docker — [инструкция устранения ошибок Windows](../docs/local-setup.md#если-frontend-не-запускается-в-windows).
