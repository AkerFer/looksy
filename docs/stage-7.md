# Этап 7: Android / Flutter

Исходники, сборка и подключение телефона: [mobile/README.md](../mobile/README.md).
[Скачать APK](https://github.com/AkerFer/looksy/raw/refs/heads/apk/android-0.1.0/Looksy.apk).

Проверено 11 ноября 2026 в облачной Linux-среде:

- `flutter analyze` — без замечаний.
- `flutter test` — 7 тестов: вход и валидация, очистка приватных маршрутов,
  CSRF, secure session contract, ротация токенов, запрет чужих URL, выход
  без соединения, защита от завершения старого входа после выхода.
- `dart run tool/api_smoke.dart` — реальный Django: регистрация, JWT,
  ротация refresh, вещи, загрузка/приватная выдача фото, генератор, избранное,
  оценки, календарь, профиль, удаление временного аккаунта и данных.
- `flutter build apk --release` — универсальный APK, 53 258 224 байта.
- `apksigner verify --verbose` — подпись v2 корректна.
- `aapt dump badging` — Looksy 0.1.0 (1), min SDK 24, target SDK 36;
  ARMv7, ARM64 и x86_64.

APK SHA-256: `bdf8eea86d288bc7e40ab7865bd506529b96627924c9c785c9590ce5415db46d`.
Подпись тестовым debug-ключом, не подпись для публикации в Google Play.
Физический Android, камера/галерея и iOS в этой среде не проверялись.
Живые Open-Meteo/Ollama по-прежнему зависят от доступности сервисов backend;
резервные алгоритмы реализованы на сервере. Offline-режима приложения нет.

Использованы Flutter 3.44.0 / Dart 3.12.0, JDK 21, Android SDK 36,
NDK 28.2.13676358. Сетевая политика Cloud блокирует storage.googleapis.com.
Для локальной сборки использованы уже установленные файлы engine той же версии
4c525dac5ebe5971c5708ef73558ed8edcf4a362 из SDK cache, с локальными Maven POM,
сгенерированными штатным скриптом Flutter engine. Совпадение байтов embedding
между тремя архитектурами проверено. Настройка локального cache находится вне
репозитория; исходники приложения и CI используют обычную сборку Flutter.
Проверка TLS и контрольные суммы скачиваемых зависимостей не отключались.
